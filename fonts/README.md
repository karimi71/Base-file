# پک منتخب ۵۰ فونت

این آرشیو شامل **۲۵ خانوادهٔ انگلیسی** و **۲۵ خانوادهٔ فارسی/عربی مناسب پروژه‌های فارسی** است. انتخاب‌ها بر پایهٔ مجوز بازِ اعلام‌شده در بستهٔ npm، کیفیت شناخته‌شده، کاربرد حرفه‌ای و تنوع نقش‌های تایپوگرافی انجام شده‌اند؛ «بهترین» در تایپوگرافی به زمینه و سلیقه وابسته است، بنابراین نقش هر خانواده نیز ثبت شده است.

- **تاریخ واکشی:** 2026-08-24
- **تعداد خانواده‌ها:** 50 (۲۵ انگلیسی + ۲۵ فارسی/عربی)
- **تعداد فایل‌های فونت:** 4,704
- **حجم فایل‌های فونت:** 90.10 MiB
- **صحت‌سنجی:** مسیر، اندازه و SHA-256 تمام فایل‌ها در [`manifest.json`](manifest.json) وجود دارد.

فایل‌های باینری فونت در مسیرهای اصلی‌شان از tarball هر بسته استخراج شده‌اند. برای هر خانواده، `SOURCE.md` و مجوز ارائه‌شده در بستهٔ اصلی (در صورت وجود) کنار فایل‌ها قرار دارد. CSS، JavaScript و محتوای نامرتبط بسته‌ها عمداً وارد آرشیو نشده‌اند.

## معیار انتخاب

1. مجوز باز یا قابل بازتوزیعِ اعلام‌شده در metadata بستهٔ منبع
2. مناسب بودن برای UI، متن طولانی، تیتر/نمایش یا برنامه‌نویسی
3. پوشش متعادل فونت‌های فارسی بومی و فونت‌های معتبرِ اسکریپت عربی برای پروژه‌های دوزبانه
4. حذف موارد تکراری و فونت‌های نامرتبط با فارسی مدرن، مانند Old Persian باستانی
